# Pon Dash VJ Helper (PDVH) - ポン出しVJヘルパー

Pon Dash VJ Helper (PDVH) は、DJとVJのシームレスなコミュニケーションと連携を実現するためのWebアプリケーションです。
DJが次にかける曲の情報をリアルタイムにVJへ送信し、VJは受け取った情報を元に即座に素材検索を行い、準備が完了したことをDJへ通知することができます。

## 🌟 主な機能

- **リアルタイム曲情報共有 (SEND to VJ)**
  - DJがプレイリストから「次にかける曲」を選び、VJへワンタップで送信。
  - DJが「SEND」ボタンを押すと、DJ画面の「VJにSENDした曲」, VJ画面の「DJからSENDされた曲」エリアが更新されて**画面全体が5秒間フラッシュ**します。DJ画面では「VJにSENDする曲」にプレイリストの次の曲が自動的に入ります。
  - Pusher を用いたWebSocket通信により、画面の更新なしで瞬時に情報が伝達されます。
- **手入力SEND機能 (VIBES! モーダル割込み送信)**
  - プレイリストにない急な選曲や手入力での割込み通知に対応するモーダル式SEND機能。
  - DJ画面の「VIBES!」ボタンからモーダルを開き、曲名・アーティスト名を手入力してワンタップ送信。
  - VJ画面側では手入力曲に**`[VIBES!]`**バッジが表示され、プレイリスト上の進行予定順序を崩さずに割込み通知が可能です。
- **VJロビー機能によるシームレスな連携**
  - VJがワンクリックで「ロビー」を作成し、6桁のコードを発行。
  - DJがそのコードを使って事前登録時に送信するだけで、自動的にVJ画面にDJのセッションが追加されます。
  - VJは複数のDJセッションを「タブ」で一元管理し、同時に複数のDJの選曲状況を追いかけることが可能です。
- **ワンクリック素材検索 ＆ タップコピー機能**
  - VJ画面およびDJ画面の「VJ検索タブ」には、素材検索用の検索ワードボックスと、Google, YouTube, ニコニコ動画, GIPHYの検索実行ボタンを配置。（検索結果は別タブで開きます）
  - 表示されている曲名やアーティスト名を**タップするだけで自動的に検索窓にコピー**され、素早い素材検索を支援します。
- **VJ READY 通知システム**
  - VJが「READY」ボタンを押すと、DJ/ VJそれぞれの**画面全体が5秒間フラッシュ**し、その後DJ画面の「VJにSENDした曲」エリアが**白文字赤背景の強調状態**（白文字黒角丸背景の[VJ READY]バッジ付き）に更新されます。
  - 暗いDJブース内でも、VJの準備完了を絶対に見逃さない視認性の高さを誇ります。
- **視認性と操作性を追求したレスポンシブUI**
  - **スマートフォン**: タップターゲット（50px高）を確保した「SEND TO VJ」(70%) と「VIBES!」(30%) のサイバーネオンテーマ横並びボタン構成。
  - **PCブラウザ**: 画面中央に固定サイズ（450x800px）で表示され、タブレットやスマホシミュレータのようにスッキリとした操作感。
  - **長文表示対応**: 長い曲名やアーティスト名は**左右スクロールで全文表示**、プレイリスト欄は**手動スワイプ（横スクロール）** で全文をストレスなく確認可能。

## 🛠 使用技術

- **フロントエンド**: HTML5, CSS3 (Vanilla / Glassmorphism UI), JavaScript (Vanilla)
- **バックエンド**: PHP (JSONベースのファイルステート管理 / 8.3系で動作確認)
- **リアルタイム通信**: Pusher API

## 🚀 デプロイとセットアップ手順

本アプリケーションはファイルベースで状態を管理するため、MySQLなどのデータベースは不要です。PHPが動作するWebサーバー（レンタルサーバ等）にファイルを配置するだけで動作します。

### 1. ファイルのアップロード

リポジトリの全ファイルを、公開したいWebサーバーのディレクトリ（ドキュメントルートなど）にアップロード・配置してください。

### 2. 環境変数の設定 (env.php)

**【重要】セキュリティ確保のための必須手順です。**
`backend/api/env.php.example` をコピーして `backend/api/env.php` にリネームし、以下の設定を行ってください。

1. **Pusher 認証情報**: Pusher のダッシュボードから取得した `App ID`, `Key`, `Secret`, `Cluster` を設定します。
   - ※ 設定した App Key や Cluster は、`backend/api/config.php` を通じてフロントエンドへ自動的に受け渡されるため、`assets/js/config.js` を直接編集する必要はありません。
2. **HMAC 秘密鍵の生成**: 認証トークン生成用の秘密鍵を設定します。
   - `$HMAC_SECRET = 'YOUR_HMAC_SECRET_KEY';` の文字列を、他人に推測されない長いランダムな文字列に変更してください。
   - 安全な鍵は、ローカルのターミナル等で以下のコマンドを実行して生成できます。
     
     ```bash
     php -r "echo bin2hex(random_bytes(32));"
     ```
3. **デバッグ環境の準備**: docker-compose.yml内のポート番号は、お使いの環境に合わせて変更してください。

### 3. パーミッションとセキュリティの確認

本番サーバーにデプロイ後、以下の設定が正しく機能しているか確認してください。

- `backend/data/` ディレクトリが、Webサーバー（PHP）から**書き込み可能**な権限（環境に応じて `755` や `777` など）になっていること。
- `backend/api/.htaccess` と `backend/data/.htaccess` がアップロードされており、これらのディレクトリ内のファイル（`env.php` や JSONファイル）にブラウザから直接アクセスできないこと。(お使いのサーバ設定に合わせてください)

### 4. ローカルでの開発・テスト (Docker)

本プロジェクトの動作検証およびテストは、原則として **Docker (`docker-compose.yml`)** を利用して行います。
以下のコマンドで Apache + PHP 8.3 のWebサーバーおよび自動テスト用 Playwright コンテナを一括起動できます。

```bash
# Docker コンテナの起動 (ポート 8000 で起動)
docker compose up -d

# テストコンテナを利用した Playwright / E2E テストの実行
docker compose run playwright npx playwright test
```

※ クイックな単体確認等で PHP ビルトインサーバーを使用する場合は `php -S localhost:8000` 等で起動可能です。

### 5. アクセスとログイン

ブラウザから `http://localhost:8000` (またはデプロイ先のURL) にアクセスします。

1. **事前登録画面**: DJが事前にプレイリストをアップロードし、操作用パスワードなどを設定してセッションを作成します。（ここで「VJロビー」へ接続することが可能です）
2. **DJ 画面 / VJ 画面**: 発行された専用URLにアクセスし、パスワード認証を経て操作画面に入ります。
3. **VJ ロビーモード**: VJはトップページの「VJの方はこちらから」ボタンで移動した VJトップページから「VJロビーを開く」を選択することで、ロビーコードを発行し、複数DJを待ち受ける専用の待機画面を起動できます。
