# Pon Dash VJ Helper (PDVH)

Pon Dash VJ Helper (PDVH) は、DJとVJのシームレスなコミュニケーションと連携を実現するためのWebアプリケーションです。
DJが次にかける曲の情報をリアルタイムにVJへ送信し、VJは受け取った情報を元に即座に素材検索を行い、準備が完了したことをDJへ通知することができます。

## 🌟 主な機能

- **リアルタイム曲情報共有 (SEND to VJ)**
  - DJがプレイリストから「次にかける曲」を選び、VJへワンタップで送信。
  - Pusher を用いたWebSocket通信により、画面の更新なしで瞬時に情報が伝達されます。
- **VJ向け ワンクリック素材検索**
  - VJ画面では、素材検索用の検索ボックスから、Google, Google画像, YouTube, ニコニコ動画, GIPHY（VJ素材用）などのボタンを押すだけで、別タブで即座に検索が可能です。
- **VJ READY 通知システム**
  - VJが「READY」ボタンを押すと、DJ画面の「VJに通知した曲」エリアが**10秒間緑色に激しくフラッシュ**し、その後**赤色の反転状態**（白文字・黒い角丸バッジ付き）で固定されます。
  - 暗いDJブース内でも、VJの準備完了を絶対に見逃さない視認性の高さを誇ります。
- **完全レスポンシブ対応**
  - **スマートフォン**: 画面全体をフルに使ったアプリライクなUI。
  - **PCブラウザ**: 画面中央に固定サイズ（600x800px）で表示され、タブレットやスマホシミュレータのようにスッキリとした操作感を提供します。

## 🛠 使用技術

- **フロントエンド**: HTML5, CSS3 (Vanilla / Glassmorphism UI), JavaScript (Vanilla)
- **バックエンド**: PHP (JSONベースのファイルステート管理)
- **リアルタイム通信**: Pusher API

## 🚀 デプロイとセットアップ手順

本アプリケーションはファイルベースで状態を管理するため、MySQLなどのデータベースは不要です。PHPが動作するWebサーバー（さくらのレンタルサーバ等）にファイルを配置するだけで動作します。

### 1. ファイルのアップロード

リポジトリの全ファイルを、公開したいWebサーバーのディレクトリ（ドキュメントルートなど）にアップロード・配置してください。

### 2. 環境変数の設定 (env.php)

**【重要】セキュリティ確保のための必須手順です。**
`backend/api/env.php.example` をコピーして `backend/api/env.php` にリネームし、以下の設定を行ってください。

1. **Pusher 認証情報**: Pusher のダッシュボードから取得した `App ID`, `Key`, `Secret`, `Cluster` を設定します。
2. **HMAC 秘密鍵の生成**: 認証トークン生成用の秘密鍵を設定します。
   - `$HMAC_SECRET = 'YOUR_HMAC_SECRET_KEY';` の文字列を、他人に推測されない長いランダムな文字列に変更してください。
   - 安全な鍵は、ローカルのターミナル等で以下のコマンドを実行して生成できます。
     
     ```bash
     php -r "echo bin2hex(random_bytes(32));"
     ```

### 3. パーミッションとセキュリティの確認

本番サーバーにデプロイ後、以下の設定が正しく機能しているか確認してください。

- `backend/data/` ディレクトリが、Webサーバー（PHP）から**書き込み可能**な権限（環境に応じて `755` や `777` など）になっていること。
- `backend/api/.htaccess` と `backend/data/.htaccess` がアップロードされており、これらのディレクトリ内のファイル（`env.php` や JSONファイル）にブラウザから直接アクセスできないこと。

### 4. ローカルでの開発・テスト

ローカル環境で動作確認を行う場合は、PHPのビルトインサーバーが便利です。

```bash
php -S localhost:8000
```

### 3. アクセスとログイン

ブラウザから `http://localhost:8000` (またはデプロイ先のURL) にアクセスします。

1. **事前登録画面**: プレイリスト（テキストやJSON等）をアップロードしてセッションを作成します。
2. **DJ / VJ 画面へのアクセス**: セッションIDが付与されたURLをDJとVJで共有します。
3. **パスワード認証**: それぞれ画面にアクセスする際、設定された4桁の暗証番号を入力してログインします。
