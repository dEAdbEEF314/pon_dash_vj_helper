# ワークスペース固有ルール (pon_dash_vj_helper)

## CHANGE_HISTORY.md の更新規則
- **追記位置**: `CHANGE_HISTORY.md` に修正・変更・追加・削除の履歴を追記する場合は、**必ずファイルの最先頭（1行目）に挿入**してください（一番上が最新、下へ行くほど古い情報になるよう保持する）。
- **フォーマット**: `日時（YYYY/MM/DD HH:mm:ss）: {修正・変更・追加・削除の内容}`

## テスト実行および成果物の配置規則
- **テスト実行環境**: 本プロジェクトにおける動作検証・自動テストは、原則として Docker (`docker-compose.yml`) 環境を利用して実施すること。
- **保存先ディレクトリ**: テスト実行・検証に必要なスクリプト、検証ログ、キャプチャ、結果レポート等のファイルは、すべて `test-results/` ディレクトリ以下に作成・生成すること。
